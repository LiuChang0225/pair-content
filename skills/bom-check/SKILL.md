# BOM 核对

对物料清单做机械可查的一致性检查，把工程师从逐行比对里解放出来。**只报告证据，不做采购或设计决策。**

## 输入

BOM 通常是 xlsx/csv。用 xlsx-processing 读取，先确认列结构（位号/料号/描述/数量/单位/封装/供应商列名各是什么），列名不标准时向用户确认映射，不要猜。

## 检查项（按序执行，逐项报告）

### 1. 结构完整性
- 必填列（位号、料号、数量）有空值 → 列出全部空值行
- 位号重复（同一位号出现两次 = 装配冲突）
- 数量为 0、负数或非整数（离散件）

### 2. 单位与量纲
- 数量单位与物料类型明显不符（电阻单位"米"、线缆单位"个"）→ 标记疑似
- 参数值量纲检查：电压/电流/功率/阻值/容值列出现数量级异常（如 100000nF）→ 按 E 系列常识标记复核

### 3. 重复与疑似错料
- 同料号不同描述（或反之）→ 数据不一致，列出成对证据
- 描述高度相似但料号不同（编辑距离小）→ 疑似重复录入或错料，标记复核

### 4. 合规对照（用户提供规则时）
- 禁用物料清单（RoHS 冲突、停产料 EOL、禁购供应商）：向用户要规则文件，逐行对照，输出违规行 + 命中的规则
- 关键器件降额检查（如电压降额 50%）需要电路上下文，超出 BOM 范围时明说做不了，不硬做

### 5. 跨版本 diff（用户给两版时）
- 新增行 / 删除行 / 变更行（同位号，字段级 diff）
- 输出为三张表；变更行标出改动的具体字段与新旧值

## 输出格式

```
## BOM 检查报告
文件: xxx.xlsx (N 行)
### 必须处理 (装配/采购会出错)
### 建议复核 (疑似问题，需工程师判断)
### 通过项摘要
```

严重度只分两档：**必须处理**（客观矛盾：空值、重复位号、禁用料命中）与**建议复核**（启发式怀疑：量纲异常、相似描述）。启发式结果永远进"建议复核"，不冒充结论。

## 守则

- 每个发现带行号 + 原始值证据，工程师要能一键定位。
- 检查是只读的：永不修改用户 BOM；要输出修正建议时生成新文件（xlsx_write）。
- 规则（禁用清单、降额标准）必须来自用户提供的文件，不从模型记忆里编造公司规范。
